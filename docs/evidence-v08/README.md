# 0.8.0 verification evidence

Original screenshots, actual test outputs and public delivery hashes. Browser tests use normal keyboard/mouse/two-finger controls and read-only canvas observations, without game setters, forced spawns, RNG replacement or test-only level shortcuts. `browser-results.json` prefixes each passed execution by context: 87 local flows, 54 direct HTTPS flows, and 11 public-bundle mirror worker migrations, 152 total executions; these include repeated requirements across delivery contexts, not 152 unique requirements. Source/scene assertions total 541.

The direct HTTPS driver uses system-CA-verified forwarding because cloud Chromium lacks the executor proxy CA. Workers are blocked only in that driver; identical audio-worklet bytes load from a Blob. The separate mirror-origin test exercises real ServiceWorker/CacheStorage/IndexedDB using the unchanged worker-listed public bytes, migrating from the released 0.7 archive. Production-origin worker installation is not claimed.

The boss timeline records genuine tenth-level handoff, real forward projectiles/HP changes, arena isolation, frozen normal distance, victory and return. The same live run uses portrait-to-landscape multi-touch shooting/jumping; it continues along naturally generated gaps, plants and all four biomes. Failed route attempts are not counted as passed controls. The original live driver's three route attempts ended early (levels 5, 2 and 18). The final driver adds safe screenshot windows, falling-enemy stomps and ordinary run retries; it does not change the game's seed, health or route. Full biome captures wait until the palette/props transition has completed. Photo filenames can fall between animation poses; texture padding/anatomy tests inspect the registered rendered resources too.

Android stills come from the API 30 offline CI test APK with a disposable CI signer. The starting frame visibly shows 0.8 and four cards. Later filenames describe sent input smoke sequences, not semantic proof of a native attack/roll/glide phase. Distinct boss shooting, jump/roll and two-finger behavior are verified separately in model/browser controls. The release APK is signed with the unchanged stable release certificate; package code/architectures/permissions/digest are checked independently. No physical-device test is claimed.

Original generated PNGs remain unchanged; registration copies only their main silhouette spans into separate padded runtime textures. Reference head/ear spans are calibrated across sheets; total silhouette height naturally varies with bent knees or outstretched wings. See ../VALIDATION.md and release BUILD-RECEIPT.json for native/package verification.
